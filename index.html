4. 安装 MetaCode ⭐（新手必看）

💡 安装前检查

确保你的电脑满足：macOS 10.15+ / Windows 10+、网络正常、至少有 2GB 可用空间

4.1 macOS 安装

打开终端

按 Command + 空格，搜索"终端"，按回车打开。

运行安装命令

curl -fsSL https://metacode.pages.dev/install.sh | sh
💡 提示

安装过程中可能需要输入电脑密码（输入时看不见字符是正常的）。安装完成后会自动验证。

验证安装

metacode --version

看到版本号（如 metacode v0.2.1）表示成功！

4.2 Windows 安装

打开 PowerShell

右键开始菜单 → 选择"Windows PowerShell(管理员)"

运行安装命令

irm https://metacode.pages.dev/install.ps1 | iex

验证安装

metacode --version
✅ 安装成功！
接下来配置 API Key 就可以开始使用了

5. 配置 API Key ⭐（新手必看）

API Key 是什么？ 就像你的"身份证号"，让 MetaCode 知道是谁在使用服务。没有它，MetaCode 无法连接 AI 服务。

5.1 获取 API Key

打开 API Key 获取页面

复制下面网址到浏览器打开：

https://napi.origintask.cn/keys/generatormckey

👉 点击直接打开

注册或登录账号

如果没有账号，点击"注册"；如果已有账号，点击"登录"。

创建 API Key

登录后，点击"创建"或"Generate"按钮。

填写 Key 名称（如"我的电脑"），选择类型和过期时间，然后点击创建。

复制 API Key

创建成功后，页面会显示一串密钥（以 sk- 开头）。立即复制保存！这个 Key 只显示一次。

⚠️ 重要
API Key 只显示这一次！如果丢失，需要重新创建。

5.2 配置到本地

打开终端

运行配置命令：

metacode config

粘贴 API Key

终端提示输入时，粘贴（Ctrl + V 或 Command + V）刚才复制的 Key，按回车。

验证配置成功

metacode exec --ephemeral --skip-git-repo-check "你好，请回复测试成功"

如果 MetaCode 回复了"测试成功"，说明配置正确！

✅ 完成！
配置只做一次，以后直接运行 metacode 就能用。

7. 核心概念详解

7.1 会话（Session）

类比：会话就像你和 MetaCode 的"对话记录本"。下次可以继续这个话题，也可以基于之前的状态开新分支。

7.2 沙箱（Sandbox）

类比：沙箱就像 MetaCode 的"游戏房"。它只能在特定区域活动，不能碰外面的东西。
模式能做什么不能做什么
只读模式读取文件、搜索修改文件
工作区模式读取+修改项目文件修改系统文件
完全权限什么都行危险！不推荐

7.3 MCP（工具连接）

类比：MCP 就像 MetaCode 的"万能插头"，让它能连接 GitHub、数据库等各种工具。

7.4 Skill（技能模板）

类比：Skill 就像餐厅的"套餐"。不问你要怎么炒菜，而是问你想要什么套餐，按标准流程做好。

MetaCode 内置多种 Skill，开箱即用：

📋 代码审查

自动检查代码质量

✍️ 写测试

自动生成单元测试

📝 生成文档

自动生成 API 文档

🔄 代码翻译

翻译成其他语言

8. 功能详解

8.1 代码理解与分析

MetaCode 能读取项目中的所有文件，理解代码结构和上下文，找出 Bug、提出优化建议。

💬 案例模拟
用户：
"这个项目有个页面加载很慢，帮我分析一下是哪里出了问题"
MetaCode：
"我分析了项目结构，发现 `index.js` 中有一个未优化的图片加载函数。建议在 `App.vue` 中使用懒加载，并将首屏不需要的图片延迟到滚动时再加载。优化后预计提升 40% 首屏加载速度。"

8.2 代码编写与修改

描述需求，它帮你创建新文件、修改现有代码、重构代码结构。

💬 案例模拟
用户：
"帮我写一个用户注册功能，包含表单验证和密码加密"
MetaCode：
"已创建 `register.js` 和 `register.html`。
✅ 表单验证：邮箱格式、手机号、密码强度
✅ 密码加密：bcrypt 加密存储
✅ 错误提示：中文友好提示
✅ 样式：简洁现代的表单样式"

8.3 Git 集成

MetaCode 深度集成 Git：状态查看、提交、推送、分支管理、冲突解决。

💬 案例模拟
用户：
"帮我查看最近的提交记录，然后创建一个 feature/login 分支"
MetaCode：
"📋 最近 3 次提交：
• abc123 - 修复导航栏样式
• def456 - 添加用户头像组件
• ghi789 - 优化首页加载速度

✅ 已创建并切换到新分支 `feature/login`"

8.4 多 Agent 协作

复杂任务可以拆分成多个子任务，由不同的 Agent 并行处理。

💬 案例模拟
用户：
"帮我重构整个后台管理系统"
MetaCode：
"好的，我将启动多 Agent 并行工作：
🤖 Agent A：重构数据库层（表结构、ORM）
🤖 Agent B：重构 API 接口层
🤖 Agent C：重构前端组件
🤖 Agent D：编写测试用例

预计 15 分钟完成，比单 Agent 快 4 倍。"

8.5 自动化与定时任务

支持定时执行任务、CI/CD 集成、钩子脚本自动化。

💬 案例模拟
用户：
"每天早上 9 点自动生成一份昨日销售报表发到我邮箱"
MetaCode：
"✅ 已设置定时任务：
⏰ 执行时间：每天 09:00
📊 任务内容：拉取昨日销售数据 → 生成报表 → 发送至 your@email.com

下次执行：明天 09:00"

8.6 非交互模式

支持一次性命令执行和管道输入，适合脚本和 CI/CD 集成。

💬 案例模拟
用户：
"在终端运行命令帮我修复所有 TODO 注释"
MetaCode：
"```bash
# 一次性任务
metacode exec \"修复所有 TODO 注释\"

# 或管道输入
echo \"优化数据库\" | metacode exec
```

✅ 已在 CI/CD 流程中集成，每次提交自动检查代码质量。"

15. 常见问题（FAQ）

❓ 安装失败怎么办？
  1. 检查系统要求（macOS 10.15+ / Windows 10+）
  2. 检查网络连接
  3. 确保有管理员权限
  4. 查看详细错误：metacode --verbose
❓ API Key 配置失败？
  1. 确认复制完整，没有多余空格
  2. 检查 Key 是否过期，重新创建
  3. 检查网络连接
❓ 如何控制成本？
  1. 从小规模开始，先用 Team 套餐
  2. 开启用量提醒
  3. 简单任务用小模型
  4. 定期查看统计：metacode usage --month
❓ MetaCode 安全吗？

MetaCode 提供多重安全保障：

  • 🛡️ 沙箱隔离 - 代码在隔离环境中执行
  • ✅ 命令审批 - 危险命令需要确认
  • 🌐 网络控制 - 可限制网络访问
  • 📝 审计日志 - 所有操作可追溯
❓ 可以离线使用吗？
可以配置本地模型使用，但功能可能受限。
❓ 如何获取技术支持？

访问 官网客服中心 获取支持，或发送邮件至客服邮箱。
