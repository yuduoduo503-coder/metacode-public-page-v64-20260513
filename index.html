安装

MetaCode 提供一行命令安装，支持 macOS 与 Windows。

macOS
Windows (PowerShell)
curl -fsSL https://metacode.pages.dev/install.sh | sh
irm https://metacode.pages.dev/install.ps1 | iex
系统要求：macOS 10.15+ 或 Windows 10+，并具备管理员权限。

配置 API Key

1
获取 API Key
打开密钥页面创建你的 Key：napi.origintask.cn/keys/generatormckey
2
写入配置
运行 metacode config，按提示粘贴 Key。
粘贴时确认复制完整、没有多余空格。
3
验证安装
运行临时测试命令，看到回复即成功： 
metacode exec --ephemeral --skip-git-repo-check "你好，请回复测试成功"

核心概念

理解这四个概念，就能用好 MetaCode。

会话（Session）
会话就像你和 MetaCode 的"对话记录本"。下次可以继续这个话题，也可以基于之前的状态开新分支。
沙箱（Sandbox）
沙箱就像 MetaCode 的"游戏房"。它只能在特定区域活动，不能碰外面的东西。支持三种模式：
模式权限
只读模式读取文件、搜索，但不修改
工作区模式读取 + 修改项目文件，但不碰系统文件
完全权限风险较高，不推荐
MCP（工具连接）
MCP 就像 MetaCode 的"万能插头"，让它能连接 GitHub、数据库等各种工具。
Skill（技能模板）
Skill 就像餐厅的"套餐"。不问你要怎么炒菜，而是问你想要什么套餐，按标准流程做好。内置技能包括：代码审查、写测试、生成文档、代码翻译等。

常见问题

安装失败怎么办？
  • 检查系统要求（macOS 10.15+ / Windows 10+）
  • 检查网络连接
  • 确保有管理员权限
  • 查看详细错误：metacode --verbose
API Key 配置失败？
  • 确认复制完整，没有多余空格
  • 检查 Key 是否过期，必要时重新创建
  • 检查网络连接
如何控制成本？
  • 从小规模开始，先用 Team 套餐
  • 开启用量提醒
  • 简单任务用小模型
  • 定期查看统计：metacode usage --month
MetaCode 安全吗？
提供多重安全保障：
沙箱隔离（代码在隔离环境中执行）
命令审批（危险命令需确认）
网络控制（可限制网络访问）
审计日志（所有操作可追溯）
可以离线使用吗？
可以配置本地模型使用，但功能可能受限。
如何获取技术支持？
访问官网客服中心获取支持，或发送邮件至客服邮箱。
