## 案例一：300 条客户评价，10 分钟出分析表

<CardGroup cols={2}>
  <Card title="用户" icon="user">
    李女士，38 岁，网店裙装店主，会基础 Excel
  </Card>
  <Card title="耗时对比" icon="clock">
    一整晚（约 4 小时）→ **10 分钟**
  </Card>
</CardGroup>

**痛点**：300 多条零散评价，人工逐条看要花一整晚。

**用户的话**：“分析顾客都夸什么、抱怨什么，把评价归类，找出最常见的 3 个投诉问题，输出成表格。”

**过程**：读取文件 → 情感分析 → 自动归类 → 统计 → 生成表格。

**交付**：分类好的 Excel 表 + 一段总结。

<Note>
  **结果**：据此调整了发货流程，差评率一个月内从 26% 降到 13%。
</Note>

*体现能力：批量文本理解、情感分类、数据清洗、结构化输出、多轮对话。*

## 案例二：销售数据，自己「开口说话」

<CardGroup cols={2}>
  <Card title="用户" icon="user">
    陈先生，45 岁，写字楼快餐店主，会导出报表但不擅长看数字
  </Card>
  <Card title="耗时对比" icon="clock">
    自己看不明白 → **15 分钟**
  </Card>
</CardGroup>

**痛点**：半年流水只有一堆数字，看不出旺季淡季，也不知道哪些菜赚钱。

**用户的话**：“分析最好和最差的月份、最受欢迎和最差的菜、周末和工作日的差异，做成图表，并给经营建议。”

**过程**：读表格 → 多维分析 → 识别高峰/低谷/异常 → 可视化 + 建议。

**交付**：图表分析报告 + 3–5 条可执行建议。

<Note>
  **结果**：实施周末策略 + 外卖配送，营收提升 30%。关键发现：周末营收只有工作日一半；销量冠军是卤肉饭。
</Note>

*体现能力：大表分析、数据清洗、多维统计、可视化、商业洞察。*

## 案例三：不会设计，也能做促销海报

<CardGroup cols={2}>
  <Card title="用户" icon="user">
    王先生，42 岁，社区便利店，无设计师、无设计软件
  </Card>
  <Card title="耗时对比" icon="clock">
    设计师 ¥200 + 等 1 天 → **5 分钟，免费，无限改**
  </Card>
</CardGroup>

**痛点**：周末促销要张海报，找设计师又贵又慢。

**用户的话**：“做一张促销海报，‘满 100 减 20’，喜庆红风格，店名‘阳光便利店’，时间本周末，手机和打印都好看。”

**过程**：理解需求 → 自动排版配色 → 生成网页海报 → 对话迭代微调。

**交付**：手机/电脑都能看的海报，可截图分享，也可 `Ctrl + P` 打印。

<Tip>
  **亮点 · 对话迭代**：王先生说“把‘减’字放大变亮、加上抽奖、红色更深一点”，30 秒重新生成。
</Tip>

*体现能力：自然语言生成设计、自动排版配色、响应式设计、对话迭代、多尺寸适配。*

## 案例四：一个新品，全平台文案一次搞定

<CardGroup cols={2}>
  <Card title="用户" icon="user">
    小林，29 岁，冷萃咖啡创业者，运营微信/小红书/抖音/公众号
  </Card>
  <Card title="耗时对比" icon="clock">
    一下午（3–4 小时）→ **10 分钟**
  </Card>
</CardGroup>

**痛点**：每上新品都要给各平台单独写文案，又费时又难保持统一调性。

**用户的话**：“新品‘冷萃手冲咖啡液’——0 添加、3 秒冲泡、适合上班族。写 3 条微信、1 篇小红书（带标题标签）、1 个抖音脚本、1 篇公众号推文，年轻化语气。”

**过程**：理解卖点和人群 → 按平台调整语气 → 生成完整文案（含标题、表情、话题标签、镜头说明）。

**交付**：3 条微信 + 1 篇小红书 + 1 个抖音脚本 + 1 篇公众号推文。

<Warning>
  **主动合规提醒**：系统标记出“最”“第一”等可能违反广告法的用词，建议改为“上班族的续命搭子”。
</Warning>

*体现能力：多平台内容创作、平台语气适配、营销钩子设计、合规风险提示。*

## 案例五：开店前的竞品调研

<CardGroup cols={2}>
  <Card title="用户" icon="user">
    阿强，33 岁，计划在二线城市开茶饮店，对市场不了解
  </Card>
  <Card title="耗时对比" icon="clock">
    自己查（一周还不清楚）→ **30 分钟**
  </Card>
</CardGroup>

**痛点**：不清楚竞争激烈程度、对手定价、自己能不能做，缺乏调研基础。

**用户的话**：“调研二线城市茶饮格局：主要品牌定价、爆款、营销打法、市场饱和度、差异化机会。”

**过程**：网络调研 → 多来源交叉验证 → 竞品对标 → 风险/机会总结 + 差异化建议。

**交付**：竞品对比表 + 市场分析报告 + 差异化清单（可溯源）。

<Note>
  **结果**：避开价格战，主打健康养生，用陈皮乌龙做差异化，3 个月内通过本地小红书建立起初始客群。关键发现：二线市场仅占 13.1%，是增长最快的机会区。
</Note>

*体现能力：网络调研、多来源交叉验证、竞品分析、战略建议。*

## 案例六：2 小时会议录音 → 纪要 + 待办（10 分钟）

<CardGroup cols={2}>
  <Card title="用户" icon="user">
    小周，30 岁，电商运营助理，每周要做会议总结
  </Card>
  <Card title="耗时对比" icon="clock">
    凭记忆手写（3 小时，常有遗漏）→ **10 分钟，完整**
  </Card>
</CardGroup>

**痛点**：每周 2 小时例会要手记笔记，总结要半天，还容易漏。

**用户的话**：“这是会议录音转写文字，按主题总结（讨论/决议），把所有待办整理成表格，含负责人和截止时间。”

**过程**：理解转写文本 → 按议程整理 → 提取决议和待办 → 识别负责人和截止时间 → 生成纪要 + 跟进表。

**交付**：按主题整理的会议纪要 + 待办跟踪表。

<Tip>
  **主动冲突检测**：系统发现“本周三前清完积压”有歧义（今天就是周三），主动请求澄清，避免了仓库混乱。
</Tip>

*体现能力：长文总结、关键信息提取、转写纠错、冲突检测、任务结构化。*
