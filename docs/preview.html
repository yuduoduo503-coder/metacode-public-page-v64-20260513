快速上手

只需三步即可开始：注册 → 安装 → 授权。授权成功后无需额外配置，直接使用。

第一步：注册账号

  1. 打开注册页面
    访问 https://napi.origintask.cn/register
  2. 用邮箱注册
    填写邮箱，完成邮箱验证。
  3. 设置密码
    设置登录密码，看到注册成功提示后即可安装。

第二步：安装

Windows

  1. 以管理员身份打开 PowerShell
    右键「开始」菜单 → 「Windows PowerShell（管理员）」。
  2. 运行安装命令
    irm https://napi.origintask.cn/install/metacode | iex
  3. 完成授权
    浏览器自动打开授权页，点击「立即授权」。
  4. 验证安装
    metacode --version
    看到版本号即成功。

macOS / Linux

  1. 打开终端
    macOS 按 Cmd + 空格，搜索「终端 / Terminal」。
  2. 运行安装命令
    curl -fsSL https://napi.origintask.cn/install/metacode | sh
  3. 完成授权
    浏览器自动打开授权页，点击「立即授权」。
  4. 验证安装
    metacode --version
    看到版本号即成功。
✅ 授权成功后无需额外配置，可直接开始使用。

版本升级

手动升级：重新运行上面的安装命令即可升级到最新版，完成后用 metacode 重启。

核心概念

理解这四个概念，就能用好 MetaCode。

会话（Session）

📒 一本「对话记录本」保留上下文，让它记得之前聊过什么；也可从某个节点开出新分支。

沙箱（Sandbox）

📦 一个「隔离的执行环境」把操作限制在受保护范围内，避免误改系统。
模式能做什么限制
只读读取文件、搜索禁止修改文件
工作区修改项目文件保护系统文件
完全权限不受限制不推荐（有风险）
⚠️ 注意「完全权限」模式不受任何限制，存在风险，一般不建议开启。

MCP（工具接入）

🔌 一个「万能转接头」让 MetaCode 能连接 GitHub、数据库等外部工具。

技能（Skill）

📋 像「菜单预设」把标准化工作流封装好，不用每次手动配置。
🔎 代码审查
🧪 写测试
📄 生成文档
🌐 代码翻译

功能详解

代码理解与分析

读取项目文件，理解结构，发现 Bug，提出优化建议。

示例：页面加载慢 → 定位到未优化的图片加载函数，建议改用懒加载，预计提速 40%。

代码编写与修改

根据需求新建文件、修改现有代码、重构结构。

示例：要做注册功能 → 生成 register.js / register.html，含表单校验、加密和错误提示。

Git 集成

深度集成：查看状态、提交、推送、分支管理、解决冲突。

示例：询问提交历史并新建分支 → 展示近期提交，创建并切换到 feature/login。

多智能体协作

复杂任务拆分给多个智能体并行处理，速度更快。

示例：系统重构 → 多个智能体同时处理数据库层、API 层、前端、测试，比单个快约 4 倍。

自动化与定时任务

支持定时执行、CI/CD 集成、基于 Hook 的自动化。

示例：每天 09:00 自动生成销售报表并邮件发送。

非交互模式

一次性执行命令、支持管道输入，方便接入脚本和 CI。

metacode exec "修复所有 TODO 注释"

echo "优化数据库" | metacode exec

常见问题

安装失败怎么办？

① 确认系统要求（macOS 10.15+ / Windows 10+）② 检查网络 ③ 确认管理员权限 ④ 查看详细报错：metacode --verbose

API Key 配置失败？

① 确认完整复制无多余空格 ② 检查密钥是否过期，必要时重新生成 ③ 确认网络连通。

怎么控制成本？

① 从团队版小规模起步 ② 开启消费提醒 ③ 简单任务用更小的模型 ④ 定期查看用量：metacode usage --month

MetaCode 安全吗？

提供多层防护：沙箱隔离、命令审批、网络管控、审计日志。

可以离线使用吗？

可以配置本地模型，但功能可能会受到限制。

如何获取技术支持？

访问官方支持中心，或发送邮件给客服。
