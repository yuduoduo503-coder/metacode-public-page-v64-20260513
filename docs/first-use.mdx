## 启动

在终端里输入：

```bash
metacode
```

进入交互式界面后，像聊天一样用自然语言说出你的需求即可。

## 常用快捷键

| 快捷键 | 作用 |
| --- | --- |
| `Ctrl + C` | 取消当前操作 |
| `↑` / `↓` | 浏览历史命令 |
| `Tab` | 自动补全 |
| `Ctrl + L` | 清屏 |
